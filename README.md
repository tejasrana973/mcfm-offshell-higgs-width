# MCFM Off-Shell Higgs Width: Lineshape and Coupling-Dependence Study

This repository holds the analysis code, datasets, and MCFM configuration
files behind a short technical note reproducing the gg → H*/continuum →
ZZ → 4l interference lineshape and using it to test the energy-independent
coupling assumption behind the standard on-shell/off-shell Higgs width
method.

Two things are done here. First, the signal, interference and continuum
pieces of the lineshape are computed with MCFM 10.3 across m(4l) =
100-1000 GeV and checked against three independent published sources.
Second, that validated lineshape is reweighted under both a standard
uniform coupling rescaling and a toy energy-dependent one, to show
directly what happens to a naive width extraction when the
energy-independence assumption fails.

## Repository layout

- **`analysis/`** -- the Python scripts that do the actual physics: the
  coupling-rescaling module, the `hwidth_ratio` validation helper, and
  the four plotting scripts.
- **`data/`** -- the two cross-section datasets the plotting scripts
  read, the extracted, validated outputs of the MCFM runs in
  `mcfm_config/`.
- **`figures/`** -- the four plots, as generated by the scripts above.
- **`mcfm_config/`** -- the MCFM input files and submission script used
  for the mass-binned lineshape scan, plus the specific runs referenced
  directly in the note: the 124-126 GeV peak-bin closure check, and the
  `hwidth_ratio` narrow-width validation. The full bin-by-bin scan logs
  are included as a zip for provenance; the numbers that matter from
  them are already in `data/lineshape_data.csv`.

## How this was actually run

In practice, every script and `.ini` file lived in the same working
directory (MCFM's `Bin/` folder for the config files, one flat folder
for the Python scripts), and the commands used were about as simple as
`python3 script.py data.csv`. The structure here organizes that for
anyone reading the repo; it isn't a literal record of the working
directory. Each script's own header comment states exactly how it was
invoked.

## Requirements

- MCFM 10.3 (not included here; see [mcfm.fnal.gov](https://mcfm.fnal.gov)) to reproduce the `.ini` runs.
- Python 3 with `pandas`, `numpy`, and `matplotlib` for the analysis and plotting scripts.
